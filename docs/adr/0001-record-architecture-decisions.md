# 1. Record Architecture Decisions

Date: 2026-07-27

## Status
Accepted

## Context
We need to record architectural decisions made on the IoT Anomaly Detection Platform so that current and future engineers understand why decisions were made and what alternatives were evaluated.

## Decision
We will use Architecture Decision Records (ADRs) based on Michael Nygard's format to document all significant architectural and DevOps decisions.

## Consequences
- Architectural intent is documented alongside the codebase.
- Engineering trade-offs are clearly communicated to stakeholders.
